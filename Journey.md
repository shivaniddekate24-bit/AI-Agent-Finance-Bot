# My Journey Building First AI-Agent-Finance-Bot

## 1. Idea & Motivation
I wanted to build an AI agent that explains **finance basics** in a simple, interactive way.  
The goal was to learn Azure AI Foundry and document the process as a portfolio project.

---

## 2. Bot Creation in Foundry
- Opened **Azure AI Foundry Playground**.
- Created a new agent named **FinGuide** (Finance Basics Bot).
- Wrote clear instructions and examples for finance concepts (payroll, ledger, debit/credit).
- Configured YAML for consistency and guardrails.

---

## 3. Testing & Preview
- Tested responses in the Playground to refine accuracy.
- Published the agent and opened it in the **Preview Web App**.
- Verified that the bot could answer finance questions interactively.

---

## 4. Documentation & GitHub
- Created a new GitHub repository: **AI-Agent-Finance-Bot**.
- Added a **README.md** with overview, setup, screenshots, and roadmap.
- Uploaded screenshots of Playground and Preview Web App.
- Added `agent-config.yaml` to preserve the bot’s configuration.

---

## 5. Learnings
- Learned how to structure an AI agent in Foundry.
- Understood the difference between Preview Web App (testing) and REST API/SDK (integration).
- Practiced documenting projects professionally on GitHub.

---

## 6. Future Plans
- Integrate REST API for external access.
- Build a custom web UI for public interaction.
- Expand bot knowledge to cover budgeting, taxation, and accounting principles.
- Host the bot on GitHub Pages or Azure Static Web Apps.

---

## ✨ Reflection
This project helped me connect **finance knowledge** with **AI tools**.  
It’s my first step toward building practical AI agents and showcasing them as portfolio projects.
